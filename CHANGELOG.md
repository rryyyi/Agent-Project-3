# Changelog

## 0.1.0 — 2026-11-25

Initial public portfolio implementation.

- Add multilingual station normalization and contextual route rewriting.
- Add validated synthetic graph, line-aware routing and auditable triples.
- Add source-preserving retrieval, RRF and optional dense/rerank/LLM adapters.
- Add bounded sessions, TTL/LRU tools cache and optional Redis fallback.
- Add FastAPI, shared Function Calling schemas and official MCP stdio tools.
- Add reviewable vector PDF geometry extraction.
- Add authored evaluation cases, timing reports, CI and container recipe.
- Document data provenance, reproducibility and operational limitations.
