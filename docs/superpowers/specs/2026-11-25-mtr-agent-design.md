## 系统组成

- Python 3.11+ 项目，`pyproject.toml` 管理包、测试、lint 与可选依赖。
- FastAPI 提供 `/health`、`/ready`、`/v1/chat`、会话接口及检索/路线工具接口。使用请求 ID、结构化异常和有界输入；默认绑定本地，部署文档覆盖认证及限流。
- Agent 编排：输入校验 → 会话上下文 → 中英粤站点别名与意图解析 → Query 改写 → 工具选择 → 检索或路线推理 → 引用与回答 → Trace。上下文有容量与过期限制，歧义追问不编造站点。
- 检索：标准化文本切片、文档与页码元数据、离线稀疏召回、可选 BGE-M3 向量召回、RRF 融合、可选 Rerank、证据压缩。明确离线检索不等于 BGE-M3 效果。
- 路线图：PDF 抽取文本位置与矢量线段，生成待审阅拓扑候选；经校验的站点、线路、相邻连接写入 JSON。图模型支持线路状态、换乘代价、路径与三元组证据，避免仅按 PDF 文本顺序拼接站点。扫描件需 OCR/视觉模型适配或人工录入。
- 路线求解：最短时间或最少换乘，输出逐段线路、站序、换乘点、演示时长与来源。未知站点、断路、同站查询均定义行为。
- 工具层：共享 JSON Schema 与参数校验；供 Function Calling 使用，另提供使用官方 MCP Python SDK 的 stdio 服务，不自行冒充协议实现。
- 缓存：有界 TTL L1，Redis 可选 L2。知识版本参与键构造；个性化问答缓存按会话隔离或仅缓存无状态工具结果。故障降级与并发安全纳入测试；不宣称未经测量的高并发性能。
- 可观测性：请求/工具耗时、脱敏 trace、失败分类；日志不输出密钥或完整私人聊天。
- 演示：命令行 + API 示例，提供中英粤问句、多轮追问、换乘路线、无答案案例。不额外构建复杂前端。
